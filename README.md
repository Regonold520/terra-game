# terra-game

my terra project is a 3d speedrunning type game inspired by the likes of pizza tower and ULTRAKILL where you have to use your wits and speed to kill enemies and progress to the end as fast as possible

Controls are:

W A S D - Movement
Space - Jump
Left Shift - Dash
Hold / tap Right click - Throw / Drop Item
E - Interact
Left Click - Swing Item

You can wallrun on walls and wall jump too.
The game so far is mostly unfinished as it is just in the beginning works but I plan to add a lot more over the coming weeks!
